# Third-party software

Marsa is built on the open-source packages below. The complete licence text of
every package compiled into a build, including transitive ones, is shown in the
app under **Settings → About → Open-source licenses**; that page is generated
from the build itself, so it is always the accurate list.

| Package | Used for | Licence |
| --- | --- | --- |
| [Flutter](https://github.com/flutter/flutter) | UI toolkit and engine | BSD-3-Clause |
| [dartssh2](https://pub.dev/packages/dartssh2) | SSH, SFTP and port forwarding | MIT |
| [xterm](https://pub.dev/packages/xterm) | Terminal emulator | MIT |
| [pointycastle](https://pub.dev/packages/pointycastle) | Argon2id, AES-GCM, RSA | MIT (Bouncy Castle licence) |
| [pinenacl](https://pub.dev/packages/pinenacl) | Ed25519 key generation | MIT |
| [file_picker](https://pub.dev/packages/file_picker) | Native file and folder dialogs | MIT |
| [path_provider](https://pub.dev/packages/path_provider) | Per-user data directory | BSD-3-Clause |

The terminal colour schemes "Dracula" and "Solarized Dark" follow the palettes
published by their respective projects (both MIT).

Marsa is not affiliated with Termius or any other SSH client.
